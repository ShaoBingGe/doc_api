**本段优先级最高。与前文任何规则冲突时，一律以本段为准。**

## A. 刷卡小票 / 收银小票必须判 `receipt`

马来西亚加油站、便利店、餐饮的**刷卡支付凭条与收银小票**，
即便票面印有 `INVOICE` / `Current Invoice` 字样，也一律判 `docType: "receipt"`。

识别特征（命中任意两条即判 receipt）：

- 窄条形票面（收银机 / POS 打印），字段竖排、点阵或热敏打印
- 含刷卡交易字段：`Card Name` / `Terminal` / `Site Id` / `Auth Code` /
  `App ID` / `App Crypt` / `Approved` / `Verification` / `Seq. Number`
- 含 `Pump` / `FuelSave` / `BUDI95` / `Subsidy` / `Litr` / `ltr` 等加油字样
- **没有买方信息**（无 Bill To / Customer / MESSRS 抬头）
- 没有独立的税额拆分表

只有同时具备**买方抬头 + 供应商税号（TIN/SST）+ 明确税额行**的正式票据，
才判 `invoice`。抬头写 `TAX INVOICE` 且有 SST/税额的，判 `invoice`。

### A-1. 手写 / 预印收据本也是 receipt

马来西亚常见的**手写现金收据本**（票面预印表格、手工填写金额）判
`docType: "receipt"`，不要因为它有编号就判成 invoice。

识别特征：

- 抬头为 `CASH BILL` / `BILL` / `RESIT` / `INVOICE`（预印），右上角有
  预印流水号 `No. 10206` 这种
- 表格为空白待填的 `Butir-Butir / Particulars`、`Kuantiti / Quantity`、
  `Harga / Unit Price`、`Nilai / Amount` 列
- 底部有 `Terima Oleh / Received By`、`Disahkan Oleh / Prepared By` 签收栏
- 内容为手写体，无税号、无买方公司信息、无税额拆分

这类单据**永远不是** invoice——它只是收款方手工开具的收款凭证。

### A-2. 什么**不算** receipt（反向边界，优先于 A 判定）

下列内容即便含刷卡字样，也一律判 `docType: "other"`，**不要**当成 receipt：

- **银行卡 / 电子钱包账单里的单条交易记录**：特征是只有一行「日期 + 商户名 +
  金额」，金额常带负号（如 `-RM 100.00`）或标注 `Transaction Date:`，
  **没有商户抬头版块、没有明细行、没有合计行、没有任何单号**。
  它是账单的一行，不是商户开出的凭证。
- **对账单 / 交易流水表**（Transaction History、Statement、账单汇总表）：
  整页是表格化的多行流水，即便每行有金额也不拆成多张票据。
- 送货单（Delivery Order）、装箱单、条款页、空白页、封面页。

**判据**：一张真正的 receipt 必然具备「**商户抬头 + 至少一行消费明细 +
一个合计金额**」三者。三者缺一，就不是 receipt。

## B. `nameOfInvoice` 必须输出票面抬头

`nameOfInvoice` 填**票面上原样印着的标题文字**，保持原大小写与原文，不翻译。
常见取值：`INVOICE`、`TAX INVOICE`、`Receipt`、`CASH BILL`、`Current Invoice`、
`RESIT`、`Bill`。

- 抬头可能在票面顶部居中，也可能在商户名之下、明细表之上。
- 票面确实没有任何标题文字时才留空；**不要用 `invoiceType` 的值去凑**。

## C. 加油 / 刷卡凭条的单号取 `Reference No`

**适用范围（务必先判断）**：仅适用于**没有明确单号标注**的加油站、
刷卡支付凭条——即票面上找不到 `Invoice No` / `Bill No` / `Receipt No`
这类明确标注、只有一堆交易系统字段的那种小票。

**票面若印有明确的单号标注，一律优先取它**，不要改取 Reference No：
`Invoice No` / `INVOICE NO` / `Bill No` / `Receipt No` / `Resit No` /
`R.No` / `Master Bill` / `Booking No`。

只有在上述标注**全部缺失**时，才按以下顺序取值：

1. `Reference No` / `Ref No` / `Ref. No` ← 首选
2. `Approval Code` / `Auth Code`（仅当连 Reference No 也没有）

**无论何种情况都绝对不要取**下列字段作为 `invoiceNumber`：
`Terminal`（终端号，常见 8 位纯数字）、`Site Id`、`Site Tran No`、`Batch No`、
`Card No`、`Seq. Number`、`App ID`、`App Crypt`、`CDB Ref No`。

**自检**：同一份文档里若两张不同的票出现**相同**的 `invoiceNumber`，
说明取错了字段（多半取成了 Terminal 或 Site Id）——回到票面重新按上表取值。

## D. 多币种票据在马来西亚场景优先取 MYR

票面同时列出外币与马币两种金额时（典型：境外平台开给马来西亚客户的收据，
如 `GRAND TOTAL USD 54.98` 与 `Total Charge MYR 224.97 (USD 54.98)`）：

- `currency` 取 **MYR**
- `totalAmount` 取**马币那一行的数值**（上例为 `224.97`，不是 `54.98`）
- 判据：马币金额通常出现在 `Total Charge` / `Amount Charged` / `结算金额` 一行，
  是**实际扣款金额**；外币行只是计价币种。

票面只有单一外币、完全没有马币行时，照原币种输出，不做换算。

## E. 明细行的 `unitPrice`

明细表里票面**印有单价列**时（`Price` / `Unit Price` / `Harga` / `@` 后的数字、
或 `12.34/ltr` 这类每单位价格），必须填 `unitPrice`。

- 加油小票的 `RM3.370/ltr`、`@RM1.380/ltr` 就是单价，填 `3.370` / `1.380`。
- 数量为 1 且票面只印一个金额时，`unitPrice` 等于该金额。
- 票面确实没有单价列、也无法从 `netAmount ÷ quantity` 直接读出时才留空——
  **不要为了填而用除法反推**（除不尽会引入假精度）。
